# Magic Mouse Linux Suite — Project Plan

The authoritative project plan is maintained in the project session/document.

Phase 0: Project Bootstrap
1. Create project directory
2. Create setup.sh
3. Create repository structure
4. Detect Linux environment
5. Check Rust toolchain
6. Install/validate dependencies
7. Initialize Cargo workspace
8. Create initial crates
9. Add basic docs
10. Add formatting/lint/check scripts
11. Run cargo check
12. Run clippy
13. Verify Phase 0
14. Move to Phase 1

Phase 1 starts only after all Phase 0 validation succeeds.
